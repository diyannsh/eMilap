# eMilap

Community lost and found interface built with React and Vite.
The GridScan room background spans the app, and pointer clicks create a ripple effect.

## Start the app

```sh
npm install
npm run dev
```

## Project layout

- `src/components/` contains the layout, GridScan background, shared panel, and individual views.
- `src/data/` contains navigation data.
- `src/hooks/` contains app hooks, including Lenis smooth scrolling.
- `src/lib/` contains shared icon exports.
- `src/styles/` contains global styles and Tailwind directives.
- `index.html`, `vite.config.js`, `tailwind.config.js`, and `postcss.config.js` configure the Vite frontend build.
